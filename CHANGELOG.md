# История изменений

## 0.4.0 — мобильный интерфейс и распространение

- Мобильное представление для установленной PWA и APK независимо от ширины; для смартфона в браузере также в альбомной ориентации. На ПК в обычном браузере сохраняется прежний интерфейс; в iframe — прежняя адаптация.
- В настройках новый подраздел «Приложение»: установка PWA через системный диалог или инструкцию браузера, установка APK через официальный GitHub Releases. Кнопки установки только в обычном браузере вне iframe.
- В PWA — ручная проверка опубликованной веб-сборки по идентификатору Git tree. При различии доступна ссылка на релизы, без скачивания или принудительной перезагрузки. Существующее кэширование и онлайн-загрузка при открытии сохранены.
- В подписанном APK восстановлена видимость проверки обновлений в мобильной навигации. Удалены фоновая проверка и баннер; кнопка релизов показывается только при наличии более новой версии. Preview отдельно от production.
- Проверка обновлений календарей остаётся самостоятельной. Формулы, алгоритмы, локальное хранение, формат резервных копий, подпись и идентификаторы Android не менялись.

### Мобильная адаптация

- Отдельная мобильная навигация «Расчёт», «Календарь», «План», «Ещё» на ширине до 760 CSS px; полноразмерный интерфейс и iframe сохранены.
- Финансовый итог и остаток дней вверху, компактные карточки отпусков с раскрытием полей, сворачиваемые оклад и подробный расчёт.
- Календарь по одному месяцу, выбор диапазона между месяцами, подсказки при нажатии; тепловая карта и подбор дат отдельно.
- Раздельные экраны годового плана, сценариев, настроек, годов, данных и справки. Системный Back учитывает мобильные экраны.
- Формулы, календари, формат хранения, подпись, в исходном мобильном прототипе CI и ресурсы PWA не менялись; в итоговом 0.4.0 добавлена маркировка веб-сборки и обновлена версия кэша. Добавлен отдельный браузерный smoke-тест; реальная приёмка Android/PWA ещё впереди.

## Unreleased — Android 0.3.0 (релизный цикл)

- Отдельная production-сборка с постоянным applicationId, версией X.Y.Z и монотонным versionCode.
- Ручной CI: подписанный APK, проверка отпечатка сертификата, SHA-256 файла, опциональная публикация через GitHub Releases.
- Исторически проверка новых версий при запуске и вручную; в 0.4.0 оставлена только ручная проверка и переход на официальный релиз. Сеть не обязательна для калькулятора.
- Android-специфичная оболочка обновлений внедряется только в генерируемые Android assets; www, формулы, календари и формат JSON не изменены.
- Добавлены 8 тестов проверки обновлений. Реальная release-сборка и установка поверх предыдущего production APK ещё требуют приёмки.

## Unreleased — Android preview 0.2.1

- Исправление двух дефектов, выявленных на Android: отдельные имена ресурсов launcher и явные ссылки в manifest; собственный обработчик системного Back через AndroidX и DOM-событие.
- CI проверяет наличие скомпилированных ресурсов иконки; подготовка ресурсов выполняется после cap sync. Добавлены пять тестов логики Back.
- Импорт JSON в 0.2 подтверждён владельцем. Проверка исправлений на устройстве ожидается.

## Unreleased — Android preview 0.2.0

- Добавлены Capacitor Preferences, однократная миграция localStorage и последовательная запись; при ошибке открытия данные не перезаписываются.
- Системное сохранение и выбор JSON через Android Storage Access Framework; сохранён формат 1.
- Иконки, оформление splash, номер сборки в настройках, обработка кнопки «Назад» и настройка клавиатуры.
- Добавлены 8 тестов адаптера хранения (моки). Формулы и календарные данные не менялись.
- CI обновляет устаревший npm lockfile при изменении зависимостей. Компиляция и приёмка preview 0.2 ожидаются.
