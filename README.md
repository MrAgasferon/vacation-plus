# Отпуск × деньги · Vacation Plus

Калькулятор финансовой выгоды ежегодного отпуска и планировщик отдыха для России.

**Веб:** https://mragasferon.github.io/vacation-plus/.

## Возможности

- Расчёт отпускных, потери оклада и разницы с обычным доходом; разбивка по месяцам.
- Графики 5/2 и 6/1, основной и дополнительный отпуск, федеральные праздники и переносы.
- Режимы «На руки» / «До НДФЛ»: меняют интерпретацию суммы, а не формулу.
- Тепловая карта, выбор дат в календаре, рекомендации и годовой план с ограничениями.
- Сравнение сценариев, локальное хранение, экспорт и импорт JSON.
- Встроенные календари 2026 и 2027; другие годы можно загрузить при наличии сети и корректных данных API.
- Поддержка изменения высоты iframe по согласованному протоколу postMessage.

Расчёты приблизительные: постоянный оклад, полностью отработанный расчётный период, делитель 29,3; без отдельного расчёта НДФЛ, региональных праздников и индивидуальных смен. Один период пока не пересекает границу года.

## Мобильный интерфейс

На экране шириной до 760 CSS px вне iframe доступны четыре раздела с нижней навигацией: расчёт, календарь, план и настройки. Полноразмерное представление сохранено. Карточки отпусков и подробности раскрываются по необходимости. Календарь показывает один месяц; выбор диапазона сохраняется при переключении месяцев.

Дополнительный браузерный smoke-тест (необязательный, не меняет CI): `python -m pip install playwright pillow`, `python -m playwright install chromium`, затем `python tests/mobile-browser.py`. Для сравнения всех десктопных экранов с предыдущим исходником передайте `--baseline путь_к_старому_index.html`. Тест использует подстановку HTML и имитацию хранилища/сети; не заменяет проверку реального PWA и Android.

## Запуск и разработка

Единственный рабочий исходник на данном этапе — `www/index.html`. Открывается напрямую или через локальный HTTP-сервер:

```sh
python -m http.server 8000 --directory www
```

Открыть http://localhost:8000/. Для проверок нужен Node.js 22 (внешние npm-пакеты не требуются):

```sh
node --test tests/*.test.cjs
```

GitHub Actions проверяет код и публикует `www/` после успешных тестов на ветке `main`. Для первого запуска выбрать Settings → Pages → Source → GitHub Actions; при необходимости запустить workflow вручную.

## Данные и перенос

Ключ браузерного хранилища `vacation-plus-v2` и JSON-формат 1 сохраняются. Перед переходом со старой страницы сделать экспорт в настройках. При другом origin данные автоматически не переносятся; разные пути одного origin могут использовать общий localStorage. Не сбрасывать старую страницу до проверки новой и резервной копии. JSON с зарплатой и отпусками не добавлять в Git.

## Развитие

См. [CHANGELOG.md](CHANGELOG.md). PWA доступна; для Android предусмотрены тестовые сборки и подписанные релизы. Внешние ссылки и получение календарей требуют сети. Условия использования исходного кода пока не оформлены отдельной лицензией.

## PWA и офлайн

Открой веб-версию по HTTPS с интернетом, дождись окончания первой загрузки и установки service worker, затем в Chrome на Android выбери «Установить приложение» или «Добавить на главный экран». Название команды зависит от браузера. После первой успешной загрузки проверь запуск в авиарежиме. Новая версия HTML загружается при следующем онлайн-открытии; при изменении набора ресурсов обновляй версию кэша в `sw.js`. В iframe и нативном Capacitor service worker не регистрируется. API календарей и пользовательские данные не кэшируются service worker; сохранения остаются в localStorage. При удалении данных сайта или вытеснении кэша офлайн-копия может исчезнуть; сохраняй резервный JSON.

## Android: тестовая сборка

Workflow `Build Android APK (preview)` запускается при изменении исходников или вручную во вкладке Actions. После успешной сборки скачай артефакт `vacation-plus-android-preview-N`, распакуй ZIP и установи `vacation-plus-preview.apk`. APK содержит файлы `www/`, не загружает интерфейс с удалённого сервера и должен запускаться офлайн даже при первой установке. Android 6.0+ (API 23), актуальный Android System WebView рекомендуется.

Используется Capacitor 7.4.5, Node 22, JDK 21, Android SDK 35. Android-проект генерируется в CI командой `cap add android` и пока не коммитится. После сборки скачай артефакт `android-npm-lock` и замени `package-lock.json` в корне репозитория. При добавлении новых прямых зависимостей CI обновляет старый lockfile, затем использует `npm ci`.

Это **debug APK** с отдельным идентификатором `io.github.mragasferon.vacationplus.preview`, не публичный релиз. Стандартная debug-подпись на новом runner может отличаться, установка поверх старого preview не гарантируется; перед удалением сохранить JSON (экспорт в Android ещё не проверен). Начиная с preview 0.2.0, Android использует Capacitor Preferences; при первой загрузке считываются существующие данные WebView, если Preferences ещё пусто. Веб/PWA по-прежнему использует localStorage. Успешная миграция очищает старые ключи калькулятора в WebView; формат резервной копии JSON 1 сохранён. При ошибке открытия Preferences запуск блокируется, чтобы не перезаписать данные.

В Android экспорт и импорт используют системный выбор документа (Storage Access Framework); доступ ко всему файловому хранилищу не требуется. При сохранении выбери локальную папку, если не хочешь помещать резервную копию в облако. JSON не зашифрован. Импорт заменяет текущее состояние только после проверки формата и подтверждения. В настройках отображается версия сборки. Иконка и экран запуска создаются из ресурсов PWA. Кнопка «Назад» возвращает на вкладку калькулятора, затем закрывает приложение после завершения очереди записей. Системные отступы настроены через Capacitor, клавиатура — adjustResize; проверка на устройствах ещё необходима.

Preview 0.1 и 0.2 запускаются на устройстве по подтверждению владельца; импорт JSON в 0.2 подтверждён. Preview 0.2.1 исправляет отсутствующую фирменную иконку и обработку «Назад» через AndroidX; повторная проверка на устройстве необходима. Перед удалением предыдущего debug APK обязательно сделай резервную копию, если данные важны. Подписанные релизы настраиваются отдельно (см. следующий раздел).


## Android: подписанные релизы

Официальные APK: https://github.com/MrAgasferon/vacation-plus/releases.
Production ID — `io.github.mragasferon.vacationplus`; отдельный от preview. При переходе экспортируй JSON из preview и импортируй в production. Для дальнейших обновлений не удаляй production: постоянная подпись, ID и возрастающий versionCode позволяют установить APK поверх предыдущего с сохранением данных.

Сборка запускается вручную через Actions → **Release Android APK** → Run workflow (ветка main). `version` — X.Y.Z, например 0.3.0. Без флага `publish` создаётся только подписанный артефакт; с флагом — также публичный релиз с тегом vX.Y.Z, APK и SHA256SUMS.txt. Перед публикацией проверяются тесты, подпись и сертификат, package ID, versionCode, ресурсы, отсутствие debug-флага и соответствие встроенного web-кода. Не переиспользовать опубликованные версии; при неудачной публикации проверить Releases на наличие черновика и устранить проблему, не перезаписывая публичный релиз. Preview продолжает собираться отдельно и не имеет доступа к release-ключу.

Для владельца: сгенерировать постоянный PKCS12 с alias `vacation-plus`, одним паролем для контейнера и ключа; хранить офлайн-резервную копию и пароль отдельно. Не помещать ключ, пароль или base64-файл в репозиторий. Настроить три Actions Secrets: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_CERT_SHA256` (SHA-256 отпечаток сертификата). Потеря ключа лишает возможности обновлять APK с прежней подписью. Доступ к изменению workflows на main должен быть ограничен доверенными владельцами.

Production проверяет публичный GitHub Releases API один раз при запуске и по кнопке в настройках. Проверка не блокирует расчёты, имеет тайм-аут и не отправляет пользовательские данные; GitHub получает обычный сетевой запрос. При обнаружении более новой версии с APK появляется уведомление; «Открыть релиз» открывает страницу официального релиза в браузере. Пользователь скачивает APK и подтверждает установку средствами Android. Приложение не загружает и не исполняет удалённый код и не запрашивает разрешение на самостоятельную установку APK. Если сеть недоступна, калькулятор работает как обычно. Web/PWA не содержат интерфейс APK-обновлений; он добавляется в сгенерированные Android assets, а `www/` остаётся неизменной.

Для приёмки: собрать 0.3.0, проверить установку и импорт, выпустить 0.3.1 с тем же ключом, увидеть уведомление в 0.3.0, установить обновление поверх, проверить данные после перезапуска, офлайн-запуск и отказоустойчивость проверки. Версия 1.0.0 — после приёмки. Реальная компиляция release и подпись проверяются на GitHub.
